# Backup destinations

- Private GitHub repository: https://github.com/alfychap/project-workflow
- Google Drive folder: https://drive.google.com/drive/folders/1pU9ZBYw5hgSj55dnsaDAS8qZG_Tz1bat
- Notion development and backup page: https://app.notion.com/p/3dd03ed1b24a81668b02f77db8ea5792?pvs=204

Backups contain the current project files, including draft skills and saved interview decisions. They do not contain the referenced conversations' unprovided attachments or the unfinished final dashboard/plugin. ZIP snapshots omit .git, backups, OS metadata and environment files. Each ZIP contains a SHA-256 file manifest.

These are point-in-time backups, not automatic synchronization. The local project folder remains the working copy.
