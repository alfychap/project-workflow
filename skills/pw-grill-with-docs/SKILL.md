# 📚 PW Grill With Docs

Use the interview behavior of `pw-grill-me`, one consequential question at a time, while maintaining the smallest durable documentation needed to prevent the same ambiguity from recurring.

Before asking, inspect only the directly relevant canonical documents and terminology sources. Separate conflicts in evidence from unanswered product choices. Ask about the choice that most changes scope, architecture, or acceptance criteria.

After each settled answer, update the existing canonical artifact when authorized and useful. Prefer a glossary entry, clarified definition, or focused section edit over a new document. Preserve provenance and do not rewrite unrelated architecture. Record unanswered conflicts explicitly.

Stop when remaining unknowns no longer affect implementation materially. Return the settled brief plus links to changed durable docs. Do not duplicate ordinary `pw-grill-me`, create an ADR system by default, or turn every clarification into documentation work.
